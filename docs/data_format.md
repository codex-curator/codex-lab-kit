# Data Format Reference

## Trial CSV Schema

The `DataCollector` exports CSV files with the following columns:

| Column | Type | Description |
|--------|------|-------------|
| `phase_id` | str | A, B, C, or D |
| `trial_index` | int | Sequential trial number |
| `object_id` | str | YCB object ID (e.g., "001_chips_can") |
| `timestamp` | float | Unix timestamp |
| `query_dhash` | str | Hex string of computed dHash |
| `matched_dhash` | str | Hex string of matched registry entry |
| `match_type` | str | EXACT, FUZZY, or MISS |
| `hamming_distance` | int | Hamming distance to matched hash |
| `image_capture_ms` | float | Image acquisition time |
| `hash_computation_ms` | float | Hash computation time |
| `registry_lookup_ms` | float | Registry lookup time |
| `total_perception_ms` | float | Total perception pipeline time |
| `llm_generation_ms` | float | LLM slow path time (Phase C) |
| `motion_planning_ms` | float | Motion planning time |
| `grasp_success` | bool | Binary grasp outcome (Phase B, C) |
| `force_actual_N` | float | Measured force (Phase B) |
| `force_planned_N` | float | Planned force from SKB (Phase B) |
| `execution_time_ms` | float | Total execution time |
| `post_action_hash_shift` | int | Hamming distance after action |
| `promoted` | bool | Whether entry was promoted to fast path |
| `llm_calls_cumulative` | int | Running LLM call count |
| `lighting_condition` | str | Lighting condition name |
| `viewpoint_index` | int | Camera viewpoint index |
| `notes` | str | Free-form notes |

## Calibration JSON Schema

```json
{
  "lab_name": "string",
  "lab_contact": "string",
  "calibration_date": "ISO 8601 timestamp",
  "camera": {
    "camera_model": "string",
    "resolution_w": "int",
    "resolution_h": "int",
    "focal_length_mm": "float",
    "working_distance_mm": "float",
    "mount_position": "string",
    "notes": "string"
  },
  "lighting_conditions": [
    {
      "condition_name": "string",
      "lux_estimate": "float",
      "source_type": "string",
      "notes": "string"
    }
  ],
  "workspace": {
    "zone_name": "string",
    "dimensions_mm": ["float", "float", "float"],
    "robot_model": "string",
    "gripper_model": "string",
    "has_force_sensor": "bool",
    "has_turntable": "bool",
    "notes": "string"
  },
  "hash_baselines": {}
}
```

## Protocol JSON Schema

See `experiment_protocol.json` generated by `ExperimentProtocol.export_protocol()`.
Contains phase definitions, object lists, trial counts, parameters, and acceptance criteria.
